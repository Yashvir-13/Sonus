# Sonus Pre-Share Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Sonus (`adaptive-music-practice`) secure, accurate, honest, shippable, and scalable for public live evaluation at `sonus.yashvirafterhours.me` and open-source GitHub contributions.

**Architecture:** Harden the existing FastAPI + SQLModel + Vite React monolith without adding new SQLModel tables or external queue/cache infrastructure. Enforce trust boundaries (bounded streaming uploads, threadpool `ffmpeg`, per-user rate & concurrency limits, `Exercise.user_id` ownership, fail-closed dev endpoints, strict HTTP security headers), wire real cognitive/coaching/benchmark flows end-to-end against PostgreSQL, modernize browser audio (`AudioWorklet`) and UI primitives (`<dialog>`, `color-scheme`, `replaceChildren`, responsive hero imagery), and scrub PII/unused scratch files while preserving `docs/`.

**Tech Stack:** Python 3.12, FastAPI, SQLModel, Alembic, Basic Pitch (ONNX), AnyIO, TypeScript, React 19, Vite 8, VexFlow 5, Clerk, Playwright, Vitest, Pytest, Mypy, Ruff, Oxlint.

**Spec:** [docs/superpowers/specs/2026-11-25-pre-share-readiness-design.md](../specs/2026-11-25-pre-share-readiness-design.md)

- Backend tests must use `@pytest.mark.anyio`; strict `mypy src/ tests/` and `ruff check src/` must stay clean.

## Review Focus

1. **Oversized or malformed audio upload (`>15 MB` compressed M4A/WAV or `0`/`-5` BPM):** Must reject with `413`/`422` RFC 9457 JSON without buffering >15 MB in memory, running unbounded `ffmpeg`, or raising `ZeroDivisionError`.
2. **Staging/unset `ENV` and cross-user access:** `/api/audio/test-transcribe` must return `404` whenever `ENV != "development"`, and `User A` must never read/overwrite `User B`'s custom exercises, sessions, or interventions.
3. **Fresh database without manual seeding:** Container startup (`docker-entrypoint.sh`) must seed the 21 canonical catalog songs idempotently; `POST /api/sessions` must return `404` for bogus exercise IDs instead of corrupting the catalog with 4-bar `"C"` rows.
4. **Guest studio & benchmark flow:** Unauthenticated visitors clicking `Enter Practice Studio` or `Peer Benchmarks` must land cleanly in interactive guest mode without forced sign-in walls, broken `<dialog>` backdrops, or fake `"N = 1,420"` cohort claims.
5. **Mid-practice pause, failed mic permission, and settings updates:** Denied mic permission must abort count-in playback cleanly; pausing must clear count-in timers and pause the waterfall RAF loop; `concertPitchHz` and `AudioContext` cleanup must leave zero leaked audio hardware handles.
